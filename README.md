PyTonal
-------

The goal here is to have one or more Python modules to 'do music theory'.

My current interest is mostly in modeling Western music theory,
with concepts like intervals and notes and keyboards and tunings and chords and such.

Examples of things we should be able to model and calculate:

- What frequency is a G#4 in Pythagorean tuning where A is 432 Hz?
- Which church mode starting on Bb has the '4 flats' key signature?
- What is the interval from C#4 to Eb3 called?

But (if this would get off the ground) it would be nice to also support,
for example, Turkish, Arab, and Indian music.

And for now this is about melody and pitch,
but rhythms are a world of their own that would be worth exploring.
